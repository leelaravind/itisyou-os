Kernel Entry & UEFI Hand-off

The critical transition phase where the bootloader relinquishes control of system resources, terminates boot services, and transfers execution to the ITISYOU kernel entry point.

1. Overview

ITISYOU OS relies on UEFI for initial hardware initialization and loading. The hand-off process is a delicate procedure that requires extracting the final memory map, exiting UEFI boot services, and setting up a minimal environment before jumping to the main kernel C/C++ code.

warning

CRITICAL REQUIREMENT

Once ExitBootServices() is called, the system is completely on its own. Attempting to use any UEFI boot service function after this point will result in an immediate page fault or unpredictable hardware behavior.

2. Retrieving the Memory Map

Before exiting, the bootloader must acquire the physical memory map. Because calling GetMemoryMap() can allocate memory, it might change the map key. A typical loop is required to ensure the key is valid when exiting.

bootloader/efi_main.c 
EFI_STATUS status;
UINTN memory_map_size = 0;
EFI_MEMORY_DESCRIPTOR* memory_map = NULL;
UINTN map_key;
UINTN descriptor_size;
UINT32 descriptor_version;

/* First call to get required size */
SystemTable->BootServices->GetMemoryMap(
    &memory_map_size, memory_map, &map_key, &descriptor_size, &descriptor_version
);

memory_map_size += 2 * descriptor_size; /* Buffer for extra allocations */

SystemTable->BootServices->AllocatePool(
    EfiLoaderData, memory_map_size, (void**)&memory_map
);

3. Exiting Boot Services

With the memory map secured, the transition occurs. The kernel parameter block (containing the framebuffer info, memory map, and RSDP pointer) is finalized.

verified

VERIFICATION STEP

Verify the status of ExitBootServices. If it returns EFI_INVALID_PARAMETER, the memory map key was stale, and you must re-fetch the map and try exactly once more.

4. The Kernel Entry Point (_start)

Execution arrives at _start in the kernel space. At this point, the system is in long mode (64-bit), but using the identity-mapped paging set up by UEFI. The first priority is switching to a dedicated kernel page table.
