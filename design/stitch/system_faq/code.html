No. ITISYOU OS is built on a custom microkernel architecture designed specifically for embedded AI processing and deterministic real-time operations. It does not utilize the Linux kernel or GNU userland.

Currently, ITISYOU OS targets specific RISC-V and ARMv9 hardware profiles. x86_64 support is in the experimental phase. See the HCL (Hardware Compatibility List) in the documentation for verified devices.
