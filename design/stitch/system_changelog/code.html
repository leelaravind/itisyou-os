Memory Allocation Overhaul

AUTHOR: SYS_ENG_01

WHAT CHANGED

Refactored the core kernel memory allocator to utilize a slab-based approach for small objects, reducing fragmentation by 24% under high concurrent load.

WHY IT CHANGED

Previous buddy allocator was causing excessive page faults during continuous I/O operations, leading to micro-stutters in the UI thread rendering cycle.
